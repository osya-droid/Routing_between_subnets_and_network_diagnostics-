# Routing_between_subnets_and_network_diagnostics-

Навчальні лабораторні роботи з дисципліни «Комп'ютерні мережі»
КНУ імені Тараса Шевченка, Кафедра кібербезпеки та захисту інформації, 2026

Лабораторна 3 — Маршрутизація між підмережами
Побудова мережі з маршрутизатором Cisco 1941 та комутатором Cisco 2960. Налаштування Serial- та GigabitEthernet-інтерфейсів, зв'язок двох маршрутизаторів через послідовний канал. Реалізація динамічної маршрутизації за протоколом RIP та перевірка таблиці маршрутів командою show ip route.

Лабораторна 4 — Діагностика мережі та усунення несправностей
Топологія з трьох маршрутизаторів (LOCAL / ISP / REMOTE) і двох комутаторів із динамічною маршрутизацією EIGRP. Аналіз доступності вузлів через ping (TTL, RTT) та трасування маршруту через traceroute. Ключова частина — самостійна діагностика несправності: методом послідовного звуження виявлено і виправлено помилкову IP-адресу на інтерфейсі віддаленого маршрутизатора.

Навички, що відпрацьовані:
1. Налаштування маршрутизаторів Cisco через CLI: інтерфейси, паролі, збереження конфігурації
2. Динамічна маршрутизація: протоколи RIP та EIGRP
3. Читання та інтерпретація таблиці маршрутизації (show ip route)
4. Мережева діагностика: ping, traceroute / tracert, аналіз TTL та RTT
5. Самостійний troubleshooting: локалізація несправності у багатовузловій топології

Інструменти:
1. Cisco Packet Tracer — симуляція мережевої топології
2. Cisco IOS 15.2 — операційна система маршрутизаторів і комутаторів
3. Обладнання: Cisco 1941 (маршрутизатор), Cisco 2960 (комутатор)
